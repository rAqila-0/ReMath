# Re:Math
Aplikasi Game Edukasi Matematika

Untuk materi di Game ini berfokus pada Operasi Hitung Dasar seperti Perjumlahan, Pengurangan, Perkalian, Pembagian, dan Campuran.

Fitur yang tersedia :
- Stage Perjumlahan
- Stage Pengurangan
- Stage Perkalian
- Stage Pembagian
- Stage Campuran

Jenis Game Untuk setiap Stage :
- Stage Perjumlahan = Drag & Drop
- Stage Pengurangan = Turn Base
- Stage Perkalian =
- Stage Pembagian =
- Stage Campuran = Simulasi Transaksi Perdagangan
