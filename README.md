# Re:Math
Aplikasi Game Edukasi Matematika

Untuk materi di Game ini berfokus pada Operasi Hitung Dasar seperti Perjumlahan, Pengurangan, Perkalian, Pembagian, dan Campuran.

Fitur yang tersedia :
- Stage Perjumlahan
- Stage Pengurangan
- Stage Perkalian
- Stage Pembagian
- Stage Campuran

Genre Game : Turn Based

Link Download Aplikasi : https://github.com/rAqila-0/ReMath/releases
